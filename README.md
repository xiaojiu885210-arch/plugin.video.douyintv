# 抖音影院 · Kodi 插件

非官方 Kodi 短视频插件。抖音没有开放官方 Kodi 接口，本插件不登录抖音、不抓取抖音首页。

## 直接下载安装包

点这个链接下载 ZIP：

**https://gofile.io/d/EpIJm5w7**

文件名 `plugin.video.douyintv.zip`

## 安装

1. Kodi → 设置 → 系统 → 附加组件 → 打开「未知来源」
2. 设置 → 附加组件 → 从 zip 文件安装
3. 选中 `plugin.video.douyintv.zip`
4. 主页 → 附加组件 → 视频附加组件 → 抖音影院

需要 **Kodi 19 Matrix** 或更新版本。

也可以点仓库绿色 **Code → Download ZIP**，解压后把里面的 `plugin.video.douyintv` 文件夹再打成 zip 安装。

## 能做什么

- 浏览内置短视频片库（分类 / 直播 / 搜索）
- 收藏（右键或上下文菜单）
- 粘贴 mp4 / m3u8 直链在电视上播放
- 在设置里填写自定义 JSON 片源地址
